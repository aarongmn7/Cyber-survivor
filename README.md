# 🎮 Cyber Survivor

Um jogo roguelike de sobrevivência com estética dark synthwave / cyberpunk espacial construído com **Canvas HTML5/JS puro (Zero-Dependency)** e **Godot 4.4 Engine**.

Deploy contínuo na Vercel:
- **Subdomínio Oficial:** [https://cybersurvivor.aaron.dev.br/](https://cybersurvivor.aaron.dev.br/)
- **Mirror Vercel:** [https://cyber-survivor.vercel.app/](https://cyber-survivor.vercel.app/)

---

## ⚡ Diferenciais de Engenharia
- **Zero-Dependency (Vanilla JS + HTML5 Canvas):** Roda instantaneamente em qualquer navegador sem necessidade de bundlers pesados ou frameworks frontend.
- **Render Loop Otimizado (60 FPS):** Atualização determinística com delta time, partículas dinâmicas, shake de câmera procedural, ondas EMP e textos flutuantes de combate.
- **Dual-Engine:** Versão Web nativa em JavaScript puro e versão compilável na engine Godot 4.4 (`main.gd`).

---

## 🕹️ Controles
- **WASD / Setas Direcionais:** Movimentação da nave
- **Espaço:** Dash tático (arrancada rápida com imunidade temporária)
- **Mira/Disparo:** Mira automática inteligente no inimigo mais próximo
- **Teclas 1, 2, 3 ou Clique:** Escolha de módulos no modal de upgrade de nível
- **M / Som:** Alternar áudio sintético
- **P / Pause:** Pausar partida
- **R / Espaço / Enter:** Reiniciar após Game Over

---

## 🚀 Como Executar Localmente
Basta abrir o arquivo `app/index.html` em qualquer navegador ou rodar um servidor HTTP local:
```bash
npx serve app
```
